Key finding: The entire src/app/api/ directory does not exist. Every data operation (books, cart, orders, wishlist, users, reviews, coupons) is currently served from in-memory mock data in src/lib/mock-data.ts and Zustand stores backed by localStorage. The Prisma schema + SQLite DB + seed script are present but no HTTP API layer connects them to the frontend.

3. Infrastructure Gaps

GapCurrent StateWhat's Needed
Authentication / Session Mock user hard-coded into Zustand; no server-side session token JWT or cookie-based session (e.g. next-auth or custom middleware) so API routes can identify the caller
Database wiring Prisma schema + SQLite exist; seed populates data; but no route ever calls prisma.* A shared src/lib/prisma.ts singleton + import prisma inside each route handler to read/write the database

Quick start: Create src/lib/prisma.ts (Prisma client singleton), then add src/app/api/books/route.ts calling prisma.book.findMany() with the same filter params the UI already sends. That single file makes the catalogue database-driven with zero UI changes.
